## 🚀 Overview

**Finance Intelligence AI** is an intelligent financial management and analytics platform designed to transform financial data into actionable insights using machine learning and data analytics.

The platform supports both personal and business financial management, helping users understand spending patterns, monitor transactions, identify unusual financial activities, analyze financial performance, and explore future financial trends.

Built with Python, Flask, Pandas, NumPy, and Scikit-learn, the system combines financial data processing, machine learning, anomaly detection, and interactive analytics in one unified application.

## ⚙️ Installation & Setup

### Prerequisites

- Python 3.13+
- Git
- Visual Studio Code
- Windows / Linux / macOS

### 1. Clone Repository

```powershell
git clone https://github.com/Alwin0606/Finance-Intelligence-AI.git
```

### 2. Navigate to Project

```powershell
cd Finance-Intelligence-AI
```

### 3. Create Virtual Environment

```powershell
py -3.13 -m venv .venv
```

### 4. Activate Virtual Environment

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```powershell
pip install -r requirements.txt
```

### 6. Run Application

```powershell
python app.py
```

### 7. Open Application

```text
http://127.0.0.1:5000
```
